# GPT Image prompt references (vendored)

Copied from [wuyoscar/gpt-image2-skill](https://github.com/wuyoscar/gpt-image2-skill)
(commit 9f8aa1a, MIT License, see LICENSE in this folder). Only the text
references are vendored; the gallery images live in the upstream repo.

Used by the image-prompt-designer through a project's editorial brief: read `craft.md`
first, then the one gallery file that matches the slot's style, and write the slot prompt
in that craft (layout and canvas first, concrete capture/camera context, scene contents
instead of adjectives, material/lighting/palette as separate controls).

| File | When |
|---|---|
| craft.md | always, before writing any photo or illustration prompt |
| gallery-product-and-food.md, gallery-photography.md | product shots, photoreal scenes |
| gallery-beauty-and-lifestyle.md | worn-in-hair / lifestyle scenes |
| gallery-illustration.md, gallery-more-illustration-styles.md, gallery-isometric.md | flat or isometric illustrations |
| templates-gpt-image-2.5.md, openai-image-2.5-generation.md, models.md | gpt-image-2.5 prompt patterns and parameter limits |
